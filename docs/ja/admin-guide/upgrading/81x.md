# GROWI v8.1.x へのアップグレード

GROWI v8.1 では、環境変数の値の読み込みが厳密になりました。従来は不正な値が黙って補正・置換されていましたが、v8.1 からは既定で起動時のエラーとなります。自前でホストしている場合は、アップグレード前に環境変数の値を確認してください。

### [要対応] 環境変数の値の厳密なチェック

GROWI v8.1 では、環境変数の値を、設定項目ごとに定められた型（数値・真偽値・JSON）に従って厳密にチェックするようになりました。このチェック（厳密モード）は既定で有効です。不正な値の環境変数が 1 つでもあると、GROWI は起動を停止します。

型ごとに受け付ける値は次のとおりです。

| 型 | 受け付ける値 | 受け付けない値の例 |
| :--- | :--- | :--- |
| 数値 | 10 進数の表記のみ（`4`、`0.5` など） | `0x1F`、`1e3`、`12abc`、`-1`、`+1`、`Infinity`、前後に空白を含む値 |
| 真偽値 | `true` / `false` / `1` / `0`（大文字・小文字は区別しない） | `yes`、`on` |
| JSON | JSON として正しい値 | 構文が誤っている値 |

数値・真偽値・JSON の環境変数に空の値を設定した場合は、未設定とみなされ、既定値が使われます。文字列の環境変数は、空の値もそのまま受け付けます。

不正な値があると、起動時に次のようなエラーが出力されます。不正な値を持つ環境変数がすべて列挙されます。値そのものは出力されません。

```text
Invalid environment variable value(s):
  - MAX_FILE_SIZE: expected a decimal number such as 4 or 0.5
Fix the value(s), or set CHECK_CONFIGURATION_VALUE_STRICTLY=false to fall back to the default values.
```

::: warning
以前の [環境変数](/ja/admin-guide/admin-cookbook/env-vars.html) ページでは、`MAX_FILE_SIZE` と `FILE_UPLOAD_TOTAL_LIMIT` の既定値を `Infinity` と記載していました。ただし、環境変数に `Infinity` を設定すると不正な値として扱われます。上限を設けない場合は、これらの環境変数を設定しないでください。
:::

AI 連携の設定に使う `AI_PROVIDERS`、`AI_PROVIDER_API_KEYS`、`AI_ALLOWED_MODELS` も、ほかの環境変数と同様にチェックされます。JSON として読めない値（エスケープの誤りなど）の場合、従来は警告のみで起動していましたが、v8.1 からは起動を停止します。JSON としては正しいものの形式が想定と異なる値の場合は、従来どおり警告を出力し、未設定として扱います。

エラーが出力された場合は、次のいずれかで対処してください。

- **値を修正する（推奨）**: エラーで列挙された環境変数の値を、上記の型に合う値へ修正します。
- **厳密モードを無効化する**: 環境変数 `CHECK_CONFIGURATION_VALUE_STRICTLY` に `false` を設定します。不正な値は既定値で置き換えられ、ログへ警告を出力したうえで起動を続けます。

`CHECK_CONFIGURATION_VALUE_STRICTLY` 自体に不正な値（`ture` など）を設定した場合は、厳密モードは有効のままとなり、エラーの一覧に含まれます。詳細は [環境変数](/ja/admin-guide/admin-cookbook/env-vars.html) を参照してください。

</ContextualBlock>

### [仕様変更] 数値の環境変数の部分的な解釈の廃止

従来は、数値の環境変数の値を先頭から読める範囲だけ解釈していました。そのため、不正な値でも一部が数値として使われることがありました。v8.1 からは、値全体が正しい場合のみ受け付けます。

| 設定値 | v8.0.x 以前 | v8.1.x 以降 |
| :--- | :--- | :--- |
| `12abc` | `12` | 不正な値 |
| `0.5` | `0`（小数点以下を切り捨て） | `0.5` |
| 構文が誤っている JSON | `null` | 不正な値 |

不正な値は、厳密モードでは起動時のエラーとなります。厳密モードを無効にしている場合（`CHECK_CONFIGURATION_VALUE_STRICTLY=false`）は、既定値が使われます。

数値の環境変数に小数を設定している場合は、v8.1 から小数点以下も反映されます。意図した値になっているか確認してください。

</ContextualBlock>


## アップグレード前にチェックすべきこと

<ContextualBlock context="docs-growi-org">

- [x] 型に合わない値の環境変数を設定していないか（`MAX_FILE_SIZE=Infinity`、`yes`/`on` のような真偽値、構文が誤っている JSON など）
- [x] `TRUST_PROXY_HOPS` または `TRUST_PROXY_BOOL` を設定しているか（設定している場合、アップグレード後に記録されるクライアントの IP アドレスを確認）
- [x] 数値の環境変数に小数を設定しているか（v8.0.x 以前は小数点以下が切り捨てられていた）
